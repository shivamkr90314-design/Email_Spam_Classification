
# Email Spam Classification

## Project Overview

Email Spam Classification is a Machine Learning
project that identifies whether a message is Spam
or Ham (Not Spam).

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Streamlit
- TF-IDF Vectorization
- Naive Bayes Algorithm

## Project Features

1. Dataset loading and validation
2. Text classification
3. Machine Learning model training
4. Model accuracy evaluation
5. Spam and Ham prediction
6. Interactive Streamlit interface

## Dataset

SMS Spam Collection Dataset.

## Installation

```bash
python -m pip install -r src/requirements.txt
```

## Run Dataset Testing

```bash
python src/check_dataset.py
```

## Train Model

```bash
python src/train_model.py
```

## Run Application

```bash
python -m streamlit run src/app.py
```

## Expected Output

The system predicts whether a given message
is Spam or Ham.

## Project Objective

To develop an automated message classification
system using Machine Learning.
